# KotaMitra

**Tagline:** Kota ka har kaam, ek jagah.

KotaMitra is a local discovery and lead-generation platform for Kota, Rajasthan. It connects customers with shops, professionals, and home-based businesses.

## Project areas

- `customer-site/` — public website for customers (first build)
- `business-panel/` — future dashboard for business owners
- `admin-panel/` — future control panel
- `backend/` — shared API and authentication
- `database/` — schema and seed data
- `docs/` — roadmap and progress

## Current status

Phase 1 started: customer website visual MVP and project structure.

## Local preview

Open `customer-site/index.html` directly in a browser, or serve the folder with any static file server.

## Important

No production credentials or user data should be committed. Use environment variables for Supabase, payment, maps, and messaging integrations when those are added.
